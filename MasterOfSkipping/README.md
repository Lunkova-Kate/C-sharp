# Лабораторная работа 1
## Консольное приложение
Прогоняет один семестр (100 дней) для одной стратегии студента.

## Входные данные: 
Сид 
## Выходные данные:
Пишет **общее удовольствие** за семестр и **среднее удовольствие в день**

# Лабораторная работа 2
## Generic Host
Крутится бесконечно, каждые 5 секунд — новый день. 
 На этом этапе нужно выделить значимые элементы логики в отдельные сервисы и подклбчить их через DI.

## Входные данные: 
сид
## Выходные данные:
После каждой итерации выводит общее удовольствие среднее адовольстиве в день. При вылете необходима остановка программы, также нужна возсожность преравть выполнение нажатиеем клавиши
